## Introduction

@zeus progress provides progress bar and circular progress components for Filament tables and Infolists.

**[Demo](https://demo.larazeus.com) · [Github](https://github.com/lara-zeus/progress) · [Discord](https://discord.com/channels/883083792112300104)**

## Features

- Circular and linear progress components
- Works in both Infolists and Tables
- Optional view publishing for customization

## Prerequisites

This package is built for Laravel and Filament.

## Installation

```bash
composer require lara-zeus/progress
```

Optionally publish views:

```bash
php artisan vendor:publish --tag="progress-views"
```

## Usage

Use `CircleProgressEntry` / `ProgressBarEntry` in Infolists and `CircleProgress` / `ProgressBar` in Tables.

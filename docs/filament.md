# Zeus Progress

The Progress Management Package for FilamentPHP provides a flexible and easy-to-use solution for tracking and visualizing progress within Filament admin panels.

## Features

- 🔥 Track and visualize progress in Filament admin panels.
- 🔥 Circular progress and progress bar components.
- 🔥 Works in both Filament Infolists and Tables.
- 🔥 Optional publishable views for customization.
